Passo 3 di 5: Installa

Installa Kalliope su Linux

Cinque passi. Ogni passo dice come capire se è riuscito. Serve un computer Linux a 64 bit con PipeWire e curl, e internet una volta per la voce (53 MB).

Versione di prova {{kalliope.version}}. Non è ancora provata in una riunione vera. Stato e limiti

Requisiti in dettaglio
  • Un computer Linux a 64 bit (x86_64): Debian 13 o Ubuntu 24.04 e successive; Fedora attuale; Arch; oppure un'altra distribuzione con l'archivio.
  • La libreria di sistema glibc 2.39 o più recente. Per controllare, scrivi in un terminale ldd --version | head -n 1: il numero in fondo alla riga deve essere almeno 2.39.
  • PipeWire con pipewire-pulse. È l'impostazione normale dei desktop recenti di Fedora, Ubuntu, Debian, Arch e openSUSE.
  • Il programma curl. I pacchetti lo richiedono; con l'archivio può mancare.
  • Internet, una volta sola, per scaricare la voce (53 MB).

    Nome del file

    Cosa si guadagna
    Si installa e si toglie con il gestore dei pacchetti.
    Cosa costa

    Fedora

    Scarica il file .rpm{{kalliope.rpm.size}}

    Nome del file
    {{kalliope.rpm.name}}
    Cosa si guadagna
    Si installa e si toglie con dnf.
    Cosa costa
    Chiede la password di amministratore. Il pacchetto non è firmato: dnf mostra un avviso e lo accetta dopo l'avviso. È previsto per questa versione.

    Arch Linux

    Scarica la ricetta (PKGBUILD)

    Nome del file
    kalliope-bin.PKGBUILD
    Cosa si guadagna
    Non compila nulla: la ricetta scarica l'archivio della versione e lo impacchetta. Si toglie con pacman.
    Cosa costa
    Non è ancora pubblicata su AUR: si usa il file della versione. Il passo 3 la scarica da solo: questo pulsante serve a leggerla prima.

    Altre distribuzioni (archivio)

    Scarica l'archivio .tar.gz{{kalliope.tar.size}}

    Nome del file
    {{kalliope.tar.name}}
    Cosa si guadagna
    Non chiede la password di amministratore: copia i file in ~/.local, solo per te.
    Cosa costa
    Per aggiornare scarichi la versione nuova e lanci di nuovo ./install.
    Come sai che è andata beneNella cartella dei download c'è un file con il nome indicato sopra, della dimensione indicata sul pulsante.
    Se non è andataScarica di nuovo. Se il browser dice che il file non esiste, la versione può essere cambiata: riparti da questa pagina.

  2. Controlla il file (consigliato)

    Serve a essere sicuri che il file sia quello pubblicato. Apri un terminale nella cartella dove hai scaricato il file (di solito Scaricati o Downloads).

    Debian e Ubuntu

    Scrivi questo comando:

    sha256sum {{kalliope.deb.name}}

    Il numero che compare deve essere uguale a questo:

    {{kalliope.sha256.deb}}

    Fedora

    Scrivi questo comando:

    sha256sum {{kalliope.rpm.name}}

    Il numero che compare deve essere uguale a questo:

    {{kalliope.sha256.rpm}}

    Arch Linux

    Il controllo lo fa la ricetta. Non c'è nulla da scrivere.

    Altre distribuzioni

    Scrivi questo comando:

    sha256sum {{kalliope.tar.name}}

    Il numero che compare deve essere uguale a questo:

    {{kalliope.sha256.tar}}

    Per controllare tutti i file insieme c'è SHA256SUMS.

    Questa versione non ha l'attestazione di provenienza (gh attestation verify): fu pubblicata quando il repository era ancora privato. Le versioni successive l'avranno.

    Come sai che è andata beneIl numero scritto dal terminale è identico a quello della pagina, cifra per cifra.
    Se non è andataNon installare il file. Scaricalo di nuovo e rifai il controllo. Se il numero resta diverso, segnalalo.

  3. Installa

    Scrivi i comandi nella stessa cartella. Per i pacchetti il computer chiede la password di amministratore.

    Debian e Ubuntu

    sudo apt install ./{{kalliope.deb.name}}

    Fedora

    sudo dnf install ./{{kalliope.rpm.name}}

    Arch Linux

    Crea una cartella vuota, scarica la ricetta e costruisci il pacchetto:

    mkdir kalliope && cd kalliope
    curl -L -o PKGBUILD {{kalliope.aur.url}}
    makepkg -si

    Altre distribuzioni

    tar -xzf {{kalliope.tar.name}}
    cd {{kalliope.tar.dir}}
    ./install
    Come sai che è andata beneScrivi kalliope --version: il terminale risponde con il numero della versione. Se usi l'archivio e il comando non si trova, scrivi ~/.local/bin/kalliope --version: ~/.local/bin può non essere nel percorso dei comandi.
    Se non è andataSe il gestore dei pacchetti dice che mancano dipendenze, controlla la distribuzione: serve glibc 2.39 o più recente (vedi «Requisiti in dettaglio»). Se il problema resta, segnalalo con il messaggio intero.
    Per togliere Kalliope

    Togli il programma:

    • Debian e Ubuntu: sudo apt remove kalliope
    • Fedora: sudo dnf remove kalliope
    • Arch: sudo pacman -R kalliope-bin
    • Archivio: dalla cartella dell'archivio, ./install --remove

    Le tue preferenze e la voce scaricata restano: stanno nella tua cartella personale, che i gestori dei pacchetti e ./install --remove non toccano mai. Per toglierle, cancella le due cartelle:

    • ~/.config/kalliope (le preferenze)
    • ~/.local/share/kalliope (la voce, 53 MB)

  4. Apri Kalliope e scarica la voce

    Apri Kalliope dal menu delle applicazioni. La prima volta la finestra dice che deve scaricare la voce. Premi «Scarica la voce» e aspetta: sono 53 MB, una volta sola.

    Poi, a ogni avvio, la finestra dice «Preparo la voce…» per un po'. Il campo di testo si accende quando ha finito.

    Come sai che è andata beneLa riga in alto dice: «Pronta. In Zoom, Teams, Meet o nel browser scegli «Kalliope» come microfono.»
    Se non è andataCerca la frase che vedi nella pagina Aiuto: ogni frase della finestra ha la sua spiegazione.

  5. Controlla che «Kalliope» sia un microfono

    Kalliope crea un microfono che esiste solo dentro il computer. Per vederlo, scrivi:

    pactl list short sources

    Se il comando pactl non c'è, salta questo passo: lo vedrai comunque nella pagina successiva.

    Come sai che è andata beneFra le righe ce n'è una che contiene la parola kalliope. Kalliope deve essere aperto.
    Se non è andataSe non c'è, la finestra lo dice: «La voce è pronta, ma …». Vai alla spiegazione di questa frase.
