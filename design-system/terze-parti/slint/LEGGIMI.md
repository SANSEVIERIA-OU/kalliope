# Il distintivo «Made with Slint»

`MadeWithSlint-logo-dark.svg` (212 × 97) è il file ufficiale di Slint, **non modificato**: il distintivo #MadeWithSlint nella versione «dark», una pillola bianca su fondo
trasparente, per i fondi scuri.

- Fonte: <https://github.com/slint-ui/slint/blob/v1.19.1/logo/MadeWithSlint-logo-dark.svg> (il tag della versione di Slint che Kalliope usa; il file è identico a quello di
  `master`, verificato il 26/11/2026).
- Impronta SHA-256: `a994c8ce0e21d008fdd5a6f23b45b5c13a2208ce5c4a8a8e8fd09c0d0cb6175b` (`sha256sum`; `tools/test_site_slint.py` la controlla sul sito costruito).

  Creative Commons Attribution-NoDerivatives 4.0»). Attribuzione: Slint (SixtyFPS GmbH). **Nessuna modifica**: non si cambiano i colori né le proporzioni; il sito la mostra
  soltanto in proporzione, a 212 × 97 px (170 al telefono).
- La licenza del programma (Slint Royalty-free 2.0, §2(b), <https://raw.githubusercontent.com/slint-ui/slint/v1.19.1/LICENSES/LicenseRef-Slint-Royalty-free-2.0.md>) chiede «the Slint
  attribution badge» su una pagina pubblica, «preferably where the binaries of your Application can be downloaded from»; la indica con un collegamento a
  `logo/MadeWithSlint-logo-whitebg.png`.
- **Perché la versione «dark» e non quella nominata dalla licenza.** `MadeWithSlint-logo-whitebg.png` è opaco, con gli angoli neri (alfa 255, pixel 0,0 = nero): sul fondo scuro del passo
  «Scarica» si vede un rettangolo nero attorno alla pillola (foto `sito-03-prove/foto-installa-distintivo-1440.png`, prima versione). Il README del logo di Slint dice: «For Dark
  mode/backgrounds, use the versions with dark». È lo stesso distintivo, con lo sfondo giusto. Se Slint chiedesse proprio quel file, basta cambiare questo file e l'impronta nel test.
- Dove sta nel sito: pagina «Installa», nel passo «Scarica», con un collegamento a <https://slint.dev/>. Componente: `componenti/distintivo.css`; catalogo: sezione «Il distintivo Slint».
- L'altra forma di attribuzione, `AboutSlint`, è in «Informazioni» nella finestra del programma (issue #21).
