## Result: any-to-any voice conversion models, evidence as of 17 Nov 2026

**Method and coverage.** I ran 16 searches and opened 83 source URLs (S01–S83). Of these, 2 PDFs were unreadable (S57, S72), 1 page was blocked by bot protection (S83), and 1 URL was a wrong guess that returned 404 (S36). About 200 further search-result URLs were not opened. They are aggregators, mirrors, forks, forum or podcast pages, or duplicates of opened sources, and I used none of them as evidence (section 7). WebFetch returns a small-model summary of each page, so quoted text is as returned. Where a number mattered, I checked it against a second page or the HTML version. Check decisive numbers in the source before use.

## 1. Synthesis (facts only, no ranking)

- **Official CPU timing with stated hardware exists for a few candidates only:**
  - MeanVC: VC module RTF 0.136 and full pipeline 0.322, single-core AMD EPYC 7542, single thread, no quantization; latency 211.52 ms [S37].
  - MeanVC2: "full pipeline RTF < 0.633 on single CPU core" (no CPU model named) and 110 ms first-packet latency [S42].
  - LLVC: RTF 2.769 and latency 19.696 ms on an Intel i9-10850K, but LLVC is any-to-one [S56].
  - Zero-VC: RTF 0.063 on Intel Xeon Platinum 8468V-2.4 GHz, algorithmic latency 20 ms [S81].
  - RT-VC: "CPU latency of 61.4 ms" in the abstract; the abstract names no hardware [S50].
  - Beatrice: the trainer README targets RTF below 0.2 single-threaded on an Intel i7-1165G7 and says conversion with existing models needs no GPU [S67].
- **Zero-shot any-to-any models with GPU-only official timing:** Seed-VC [S11], StableVC (RTX 3090, RTF 0.146) [S31], GenVC (H100, A100, 1080 Ti) [S63], StreamVoice (A100 80G, 124.3 ms) [S60], StyleStream (laptop RTX 4060 demo, 1 s latency) [S53].
- **A third-party benchmark inside an official paper:** the MeanVC paper's Table 1 lists Seed-VC (25M) at RTF 7.039 and StreamVoice (101M) at RTF 13.632, both on one EPYC core for the VC module [S37]. Seed-VC's own README calls its tiny model "suitable for real-time voice conversion" and recommends a GPU [S11]. Scope differs.
- **ONNX:** no official ONNX export was found for any VC candidate.
  - Community ONNX for VC: MeanVC2 (kiarina, conversion graphs Apache-2.0, speaker encoder CC BY-SA 3.0) [S45]; Chatterbox VC (TigreGotico, Apache-2.0; about 1,081 MB fp32, 468 MB int8) [S35]; OpenVoice V2 (aoiandroid, "not an official MyShell release", repo private) [S20].
  - Resemble's official ONNX repo covers Chatterbox Turbo TTS, not VC [S80].
  - Beatrice v2 has an "onnx" edition in w-okada's VCClient, a third-party client [S68].
- **Italian:** no official source evaluates any candidate on Italian.
  - Italian appears only as a supported language in Chatterbox Multilingual (a TTS model with a VC script; Italian VC not verified) [S32] and in FreeSVC (singing, CC BY-NC-SA) [S70].
  - MLS, one of GenVC-large's training sets, includes Italian [S78][S63].
  - Explicit limits: Vevo training is Emilia, six languages without Italian [S26][S29]; OpenVoice V2 natively supports six languages without Italian [S17]; MeanVC is Mandarin-only in training and evaluation [S37]; LLVC is "clean English speech" only [S56]; kNN-VC is English [S04]; Phoneme Hallucinator is English-only [S09]; Zero-VC trained on English LibriTTS [S81]; StreamVoice on Chinese data [S60]; X-VC evaluated in English and Chinese [S47].
- **Licences (code and weights reported separately; "commercial" is per the licence name, not a legal opinion):**
  - Permissive: OpenVoice V2 code and weights MIT [S17][S18]; Applio code and weights MIT [S21]; GenVC code and weights MIT [S63][S65]; X-VC code MIT [S48]; Chatterbox code and weights MIT [S33][S32]; MeanVC and MeanVC2 weights Apache-2.0 [S38][S42]; kNN-VC code MIT [S02] (weights not stated); LinearVC code MIT [S07]; FreeVC code MIT [S23]; LLVC code MIT [S54]; RVC code MIT [S22].
  - Non-commercial by licence name: Vevo cc-by-nc-4.0 [S26]; Vevo1.5 and Vevo2 weights cc-by-nc-nd-4.0 [S27][S28]; FreeSVC cc-by-nc-sa-4.0 [S70]. The Amphion repo is MIT, but it says the Emilia dataset is CC BY-NC [S25].
  - Copyleft: Seed-VC code and weights GPL-3.0 [S11][S13]; so-vits-svc AGPL-3.0 [S61].
  - Not stated: RT-VC code [S52], StableVC, StreamVoice, Zero-VC, the X-VC checkpoint (HF card MIT [S49]), Phoneme Hallucinator [S10], RVC pretrained models [S22], LinearVC checkpoints, kNN-VC weights.
- **Maintenance status:** Seed-VC archived 21 Nov 2025 [S11]; so-vits-svc archived 11 Nov 2023 [S61]; Chatterbox "retired research and no longer maintained" as of August 2026 [S33]; Applio "will no longer receive frequent updates" [S21]; Beatrice 2 at release candidate 2.0.0-rc.3 [S66].

## 3. Notes per model

- **kNN-VC** [S01][S02][S03][S04]. The README says "kNN is non-parametric and does not require any training." It says quality gains "diminish beyond 5 minutes" and that "the longer the cumulative duration ... the better." Limitations: clean reference needed; longer references run slower. The paper says that with limited data "intelligibility and target speaker similarity decrease to a point where the more complex baselines perform better." The paper's HTML states "with as little as five seconds of target speaker audio, we can still retain moderate intelligibility." The LICENSE fetch returned MIT with an added sentence about considering software copyright; verify the raw text by hand.
- **LinearVC** [S05][S06][S07][S82]. Interspeech 2025, pp. 1398–1402. The paper abstract: "We find that just rotating the features is sufficient for high-quality voice conversion" and "a rank of just 100 gives competitive conversion results." The code repository lists WavLM-Large and HiFi-GAN and loads kNN-VC checkpoints via torch.hub. No RTF, no languages, no sizes.
- **Phoneme Hallucinator** [S08][S09][S10]. Abstract: "one-shot VC model ... based just on a short target speaker voice (e.g. 3 seconds)." Trained on English only; the cross-lingual table is empty on the project page. The repo lists no licence and offers only a Colab notebook for inference. Python 3.6.3 and TensorFlow 1.15.5 are pinned.
- **Seed-VC** [S11][S12][S13][S14][S15][S77]. Release table (params): seed-uvit-tat-xlsr-tiny 25M ("suitable for real-time voice conversion"), seed-uvit-whisper-small-wavenet 98M ("offline"), seed-uvit-whisper-base 200M (singing), hubert-bsqvae-small v2.0 67M CFM + 90M AR. Real-time: "algorithm delay of ~300ms and device side delay of ~100ms"; measured on an RTX 3060 Laptop GPU: 430 ms latency, 150 ms inference per chunk. "It is strongly recommended to use a GPU for real-time voice conversion." The ASTRAL-quantization repo (GPL-3.0, archived 21 Nov 2025) uses HuBERT-large features and gives no sizes [S15]. I found no Seed-VC v2 paper.
- **OpenVoice V2** [S17][S18][S19][S20]. Languages: "English, Spanish, French, Chinese, Japanese and Korean are natively supported." The paper gives no size and no RTF; its licence is CC BY-NC-SA 4.0 while the code and weights are MIT.
- **RVC / Applio** [S21][S22]. RVC: "Easily train a good VC model with voice data <= 10 mins!" and "at least 10 minutes" of low-noise data. The page gives no CPU training time. The HuBERT base and RMVPE sizes are not listed. ContentVec is named only in a reference list. Applio: "Applio will no longer receive frequent updates."
- **FreeVC** [S23]. WavLM-Large with an information bottleneck; trained on VCTK; MIT. The paper (arXiv 2210.15418) was not read.
- **Vevo family** [S24][S25][S26][S27][S28][S29][S79]. Vevo-Timbre is style-preserved VC; Vevo-Voice is style-converted VC. Vevo1.5 and Vevo2 are speech and singing models. The HF pages list no RTF, no CPU figure and no ONNX mention. The Vevo2 arXiv abstract gives no reference length and no RTF.
- **StableVC** [S30][S31][S83]. The paper says 166M parameters for "the acoustic model" only. The timing table reports RTF 0.146 on an RTX 3090. Stated limitations: "potential timbre leakage"; UTMOS drops from 4.12 at 10 steps to 3.42 at 1 step. The AAAI page was blocked.
- **Chatterbox VC** [S32][S33][S34][S35][S80]. Script: `from chatterbox.vc import ChatterboxVC`, `generate(audio=..., target_voice_path=...)`, device auto-detected (cuda, mps, else cpu). The repo says the project is "retired" as of August 2026 and offers "no support, updates, or paid tier." The Nano TTS (English, 110M) runs "3x faster than realtime on 8 CPU cores" (TTS, not VC). The HF card warns that "language transfer outputs may inherit the accent of the reference clip's language." Outputs carry a watermark.
- **MeanVC** [S37][S38][S39][S40]. The paper gives the latency split: 160 ms chunk, 51.52 ms inference, 211.52 ms total. "We evaluate both RTF and latency of all VC models on a single-core AMD EPYC 7542 CPU with single-threaded execution." Limitations: "MeanVC lags behind Seed-VC in DNSMOS"; quality degrades at 80 ms chunks. The project page says "intended solely for academic research and ethical, non-commercial use" [S40].
- **StreamVoice** [S59][S60]. Latency "124.3 ms" is "Speed tested on an A100 80G GPU." The paper says "the total pipeline only has 124 ms latency." The paper gives no release statement for its own code. It cites third-party code only.
- **RT-VC** [S50][S51][S52]. Code repository "Official implementation of the paper". Model size, reference length and hardware are not on the pages read.
- **Beatrice v2** [S66][S67][S68]. The official page says v1 runs "CPU シングルスレッドで動作" (single-threaded CPU) at about 35 MB and about 0.05 s latency measured externally. v2 minimum CPU is "Intel Core 4th gen or later / N100." The trainer README says "既存の学習済みモデルを用いて声質の変換を行うだけであれば GPU を必要としません" (converting with existing models needs no GPU). The VCClient table lists Beatrice v2 under onnx (win, mac) and "独自" (custom) licence.
- **GenVC** [S62][S63][S64][S65][S78]. Latency table on GPUs: H100 95.2 ms, RTF 0.28; A100 129.7 ms, RTF 0.38; 1080 Ti 183.9 ms, RTF 0.57. No CPU run.
- **LLVC** [S54][S55][S56][S58]. "Our choice of training data contained only clean English speech." Fixed target speaker (any-to-one). The paper's HTML names the CPU; the abstract says "consumer CPU" only. Memory use not measured.
- **so-vits-svc** [S61]. Archived; AGPL-3.0; the README points users to 34j/so-vits-svc-fork and w-okada/voice-changer.
- **MeanVC2** [S41][S42][S43][S44][S45]. Components: streaming Fast-U2++ ASR, ECAPA-TDNN with WavLM upstream, vocoder Vocos, DiT decoder (4 layers, 512 dim). Community ONNX (kiarina) per-chunk timings, median (fp32 / int8), 160 ms chunk, 3 ODE steps: MacBook Pro M1 Max 19 / 14 ms; Core i9-12900K 25 / 15 ms; iPad Air 4 29 / 18 ms; Pixel 6 69 / 54 ms; Pixel 6 real-time 5-minute run at 2 threads averaged 92 ms (int8) and 103 ms (fp32). The ONNX card warns: "This is one listener, so listen on your own material before relying on it."
- **X-VC** [S47][S48][S49]. Code and checkpoint released per the README ("Official code release"). Offline RTF "substantially lower" than baselines, with no numbers.
- **Zero-VC** [S46][S81]. Algorithmic latency "20 ms"; the arXiv abstract page itself has no RTF, but the HTML gives 0.063 on Xeon 8468V. "Accepted to Interspeech 2026." Code and checkpoints: no statement.
- **StyleStream** [S53]. Abstract (search): "end-to-end latency of 1 second." The project page: "Real-time demo running on-device on a laptop with RTX 4060" describes the video demo, not a measurement of the 1 s figure.
- **REF-VC** [S16]. Claims comparable to Seed-VC on clean data and better on noisy data; "4 steps." No timing, sizes or code.
- **FreeSVC** [S70]. Singing VC; "Italian | 5 | ✅ Full | Part of CML"; "can only be used for research and non-commercial purposes."

## 4. Conflicting evidence

1. **MeanVC / MeanVC2 terms.** Apache-2.0 on HF [S38][S42] and on the GitHub README [S39]. Project pages say "research demonstration purposes only" and "non-commercial" [S40][S43]. The MeanVC2 arXiv paper is CC BY-NC-SA 4.0 [S41]. These attach to different things (weights, demo, paper). I did not resolve which governs.
2. **Vevo2 weights.** HF metadata cc-by-nc-nd-4.0 [S28]. A third-party mirror (AEmotionStudio, search snippet only) is tagged MIT. The Amphion repo says "MIT License. It is free for both research and commercial use cases" but gives no weights licence [S25].
3. **X-VC version.** A search summary called v2 (22 Apr 2026) the latest. The arXiv abstract page lists v3 (4 Sep 2026) [S47].
4. **Vevo2 title.** A search snippet gave the v1 title "Bridging Controllable Speech and Singing Voice Generation via Unified Prosody Learning." The current abstract page title is "Vevo2: A Unified and Controllable Framework for Speech and Singing Voice Generation" [S79].
5. **StableVC speed claim.** The abstract says "about 1.65x faster" than diffusion baselines. The fetched Table 1 gives 0.146 (StableVC) and 0.287 (DDDM-VC); the tool's own calculation is about 1.97x. This is a single tool calculation, so check the paper's table [S31].
6. **Zero-VC RTF.** The arXiv abstract page omits it; the HTML gives 0.063 [S81].
7. **RT-VC hardware.** A search summary says "Apple M3 CPU" (not opened, attributed to the paper). The arXiv abstract names no hardware [S50]. Not resolved.
8. **Seed-VC timing.** README: GPU, 430 ms latency [S11]. MeanVC table: RTF 7.039 on a single EPYC core [S37]. Different metrics, scopes and hardware.
9. **OpenVoice licence.** Code and weights MIT, "Free for both commercial and research use" [S17]; the paper is CC BY-NC-SA 4.0 [S19].
10. **Chatterbox licence.** MIT on GitHub and HF [S33][S32]; a third-party mirror (search snippet) says Apache-2.0.
11. **Beatrice v2 terms.** Custom per VCClient ("独自") [S68]; the official page says contact the project for the official library [S66]; the trainer repo is MIT [S67]. A search summary called the API licence "proprietary" (a Japanese readme, not opened).
12. **so-vits-svc archive date.** GitHub says 11 Nov 2023 [S61]; a Chinese wiki snippet says 5 Nov 2023 (search only).
